# Pong Game

Classic two-player Pong game written in C using SDL2.

## Controls

Left Player:
W - Move Up
S - Move Down

Right Player:
UP ARROW - Move Up
DOWN ARROW - Move Down

## Features

- Two player Pong
- Paddle movement
- Ball physics
- Collision detection
- Score system
- Winner detection
- Restart with R key

## Build

make

## Run

./pong
